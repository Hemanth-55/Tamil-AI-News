# Session start

1. `git pull --rebase` so you have every other session's work (several sessions share this repo).
2. Read the top 3 entries of `notes/session-log.md`, plus `notes/backlog.md` and `notes/decisions.md`.
3. Brief Hemi in 3–5 short lines (simple English / Tanglish): last session, open branches, top backlog items. Then ask what to work on.
4. Facts come only from the repo, the notes and Hemi. If something isn't written down, ask; never guess.
